# フロンティア開拓記 (Frontier Outpost)

資源(木材・食料)を生産し、市場で売買・交換しながら拠点の建物をアップグレードして拡張していく、開拓シミュレーション風のブラウザゲーム(PWA)。

「ホワイトアウトサバイバル」的な拠点拡張・資源生産・市場売買のループを、スマホでも遊べる軽量なPWAとして試作しています。

## 現在の状態: v0.1.0 (縦切りプロトタイプ)

最初の一本道の核ループのみを実装した段階です。

- 🏰 **本拠地**: 他の建物のレベル上限を決める中心施設。上げると倉庫・市場が解放される。
- 🪓 **伐採小屋**: 木材を自動生産(アイドル方式、離れていても時間経過で貯まる)
- 🏹 **狩猟小屋**: 食料(肉)を自動生産
- 📦 **倉庫**: 木材・食料の貯蔵上限を拡張
- ⚖️ **市場**: 木材・食料をゴールドで売買(本拠地Lv.2で解放)

まだ入っていない要素(今後の拡張候補): イベント機能、ヒーロー/キャラ育成、対人・アライアンス要素、拠点の見た目(マップ配置)、複数資源(鉱石など)、建物の種類追加。

## 遊び方 / ローカル起動

Node.js等は不要。Pythonの簡易サーバーで確認できます。

```bash
py -3 -m http.server 8795 --directory .
```

その後 `http://localhost:8795` を開く。

## データ保存

ブラウザの `localStorage` にのみ保存(バックエンドなし)。ブラウザデータを消すとリセットされます。アプリ内の設定(⚙️)からも手動リセット可能。

## 技術構成

- 単一ファイル `index.html`(HTML/CSS/JS すべてインライン)
- `manifest.json` / `sw.js` でPWA化(ホーム画面追加・オフライン起動に対応)
- Service Workerは network-first 戦略(常に最新版を優先、オフライン時のみキャッシュへフォールバック)
