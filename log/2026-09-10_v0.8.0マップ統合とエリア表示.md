# 2026-09-10 v0.8.0 マップ統合とエリア表示

## 経緯
v0.7.0に対するフィードバック:

- 行動マップは5×5マスに設定
- 木材伐採エリアはマップ移動ではなくドアから直結にすること
- マップ移動演出はカット(扉開閉エフェクトは残す)
- NPCが伐採中は、伐採している木にNPCが配置されること(1本の木に1NPC)
- 売買NPCが雇われているときは、売買の箇所に売買NPCを配置すること
- 木は9本に設定(等間隔に並べること)
- NPCカウンタと効率化カウンタをエリア表示に変更(該当エリアに行くことでフォームが選択できる)
- 効率化やNPC雇用はエンターキーを押すことで実行可能にする(その中での選択でもエンターキーや十字キーを有効)

## 実装内容(かなり大規模な作り直し)
- **拠点+森を1枚のマップに統合**: これまで`baseGroup`/`forestGroup`の2つのTHREE.Groupを切り替えていた構成を、
  単一の`world.group`に統合。`blockedInBase`/`blockedInForest`の2関数も、拠点ゾーン(`BASE_MIN..BASE_MAX`
  = -2..2、5x5マス)・門の行(`z===DOOR_Z`)・森ゾーン(`FOREST_MIN_Z..FOREST_MAX_Z`)を連続してjudgeする
  単一の`blocked(x,z)`関数に統合。`state.player.map`フィールドも廃止(座標だけで拠点/森どちらにいるか
  自然に決まるため)。
- **マップ切替演出(transitionステートマシン・暗転オーバーレイ)を全廃**: `startDoorTransition`/
  `updateTransition`/`setFade`/`.fade-overlay`をすべて削除。扉を越える移動は他の1マス移動と
  完全に同じ処理(`attemptStep`→`blocked()`判定→`beginStep()`)になった。
- **扉の開閉演出は残す**: `updateDoorSwing()`を新設。プレイヤーが扉(z=3)から一定距離内にいるかどうかで
  開閉の目標値を決め、`doorSwing`を毎フレーム線形補間するだけの軽量な実装(移動はブロックしない、純粋な演出)。
- **伐採NPCの木への配置**: 雇用時に`assignTreeToWorker()`で他のNPCが使っていない木を1本割り当て
  (`treeIdx`をworkerオブジェクトに保持)、`harvestWorkerVisualPos()`でその木のすぐ脇にメッシュを配置。
  木9本・上限5体なので必ず空きがある前提。
- **売買NPCの売買ポイントへの配置**: `sellWorkerVisualPos(i)`で売買ポイントを中心とした小さな円周上に
  配置(複数体でも重ならないよう角度をずらす)。
- **木を9本・等間隔に変更**: `TREE_DEFS`をx∈{-2,0,2}・z∈{5,7,9}の3×3格子(間隔2マス)で生成するループに変更。
- **NPCカウンター・効率化カウンターのエリア表示**: 各カウンターの設置マスに`addPad()`で色つきの床パッドを追加
  (NPCカウンター=オレンジ、効率化カウンター=青)。カウンターの当たり判定(そのマス自体は侵入不可)は従来通り、
  隣接マスから`INTERACT_RADIUS`内であれば操作できる。
- **エンターキー対応**: `activeModal`("eff"|"npc"|null)と`modalSelIndex`を新設。エリア内でEnterを押すと
  対応するモーダルを開き(`openEfficiencyModal`/`openNpcModal`)、モーダル表示中は矢印キーが移動ではなく
  項目選択(`modalSelIndex`の増減、上下・左右どちらでも可)に、Enterが選択項目の実行
  (`buyUpgrade`/`hireWorker`)に、Escapeが閉じる操作に割り当てられる。選択中の項目は`.eff-row.selected`
  のハイライト(金色の枠)で視覚的に分かるようにした。タップ操作(🛠️/👷ボタン、モーダル内のボタンクリック)も
  従来通り併用可能。

## 動作確認
Browserペイン(モバイル375x812)で確認。一時的なデバッグフック(`window.__dbg` / `window.__frame` /
`window.__press` / `window.__hireWorker` / `window.__giveGold` / `window.__key`)を仕込んで検証後に削除。

- 拠点(5x5)から森へ、シーン切替やフェードなしにそのまま歩いて移動できることを確認(座標が
  z=1→4と連続的に変化するのみ)
- 扉付近にいる間だけ`doorSwing`が1(開)に、離れると0(閉)に戻ることを確認
- 木9本が指定通りの等間隔3×3配置になっていることを確認
- 伐採NPCを2体雇うと、それぞれ異なる`treeIdx`(0, 1)が割り当てられることを確認(木の奪い合いが起きない)
- 拠点の効率化カウンター付近でEnterキーを押すとモーダルが開き、矢印キーで選択が移動し(ハイライト表示も
  追従)、Enterキーで正しい項目が購入されること、Escapeキーで閉じられることを確認
- モーダル表示中は矢印キーでプレイヤーが移動しないことを確認
- コンソールエラーなし

## 残課題・今後の候補
- 伐採NPCが担当の木に立っている間も、木自体の見た目(切り株化)はプレイヤーの手動伐採時のみ変化する
  (NPCの伐採では木の見た目は変わらず、数値上のみ生産される)。将来的に統合できる余地あり
- 扉の開閉判定距離やアニメーション速度は仮値。プレイ感を見ながら調整する想定
- モーダルを閉じるキーボード操作(Escape)は明示的な依頼ではなく、キーボードのみでの操作性を保つための
  追加。不要であれば削除も可能
